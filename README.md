# tgether.pl

Strona firmowa TGether. Statyczny HTML, bez procesu budowania.

## Hosting i deploy

Strona jest hostowana na **GitHub Pages** z gałęzi `main` tego repozytorium.
Każdy push do `main` publikuje się automatycznie na https://tgether.pl
(domena spięta plikiem `CNAME`, DNS wskazuje na GitHub Pages).

## Do zrobienia po starcie

- Formularz demo: podmień `TWOJ_FORMSPREE_ID` w `index.html` na identyfikator
  z formspree.io (do tego czasu formularz robi fallback na mailto).
- Polityka prywatności: uzupełnij dane rejestrowe oznaczone [do uzupełnienia].
